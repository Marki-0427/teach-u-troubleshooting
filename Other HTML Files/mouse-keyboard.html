Mouse & Keyboard Not Working

Let's start with a few safe checks.

Before you start
  • Keep liquids away: Never spray cleaner on a plugged-in keyboard or mouse. Unplug it before cleaning.
  • Do not stretch cables: Leave some slack so the cable does not pull at the plug.
  • Check batteries: Use matching batteries in wireless devices; do not mix old and new.
  • Do not open the PC case yet.
