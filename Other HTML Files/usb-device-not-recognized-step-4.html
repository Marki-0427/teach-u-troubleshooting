USB Device Not Recognized

4 Restart and check Device Manager.

Save your work and restart Windows. If it still fails, open Device Manager and look for a warning symbol under Universal Serial Bus controllers.

✓What to check:
  • Restart before troubleshooting drivers.
  • Note any exact error message.
  • Use Windows Update or the PC maker’s support site for driver help.
