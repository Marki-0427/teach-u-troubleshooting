Blue Screen or Unexpected Restart

1 Record the error message.

If a blue screen appears, note the stop code and any file name shown. If it restarts too quickly, record the next message with a photo.

✓What to check:
  • Write down the exact code.
  • Note what you were doing before the error.
  • Check whether it began after an update or new device.
