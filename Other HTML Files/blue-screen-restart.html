Blue Screen or Unexpected Restart

A blue screen can have several causes. Start with recent changes and protect your files.

Before you start
  • Write down the stop code or take a photo of the error.
  • If the PC is repeatedly restarting, avoid repeated forced shutdowns unless it is unresponsive.
  • Back up important files whenever Windows stays available.
