USB Device Not Recognized

1 Reconnect the USB device.

Unplug the device, wait a few seconds, and reconnect it firmly. If it is a storage drive, check whether it appears in File Explorer.

✓What to check:
  • Try one reconnect.
  • Check the device’s indicator light if it has one.
  • Do not format a drive just because Windows cannot read it.
