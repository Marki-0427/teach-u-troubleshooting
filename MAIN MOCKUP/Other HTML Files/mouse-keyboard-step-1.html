Mouse & Keyboard Not Working

1 Check the USB connection.

Make sure the mouse or keyboard cable is firmly plugged in. Try a different USB port and check for visible cable damage.

Plug directly into the computer instead of a USB hub if possible.
✓What to check:
  • Is the plug fully inserted?
  • Try another USB port.
  • Look for a bent connector or damaged cable.
