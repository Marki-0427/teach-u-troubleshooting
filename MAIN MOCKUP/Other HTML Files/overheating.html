Overheating

Let's start with a few safe checks.

Before you start
  • Power down first: Shut down and unplug the computer before cleaning external vents.
  • Keep vents clear: Leave space around the tower for airflow.
  • Never open the power supply: It can retain dangerous electrical charge.
  • Do not use liquids inside the computer. Ask a technician if internal cleaning is needed.
