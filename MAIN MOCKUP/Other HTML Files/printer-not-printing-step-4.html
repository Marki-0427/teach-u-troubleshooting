Printer Not Printing

4 Run the printer troubleshooter.

Open the printer settings and use the available Windows troubleshooter, or check the manufacturer’s official support page for your model.

✓What to check:
  • Restart the printer and PC if needed.
  • Install recommended official driver updates.
  • Contact support if jams, error codes, or connection failures continue.
