Blue Screen or Unexpected Restart

3 Install updates and check free space.

If Windows stays on, back up important files, install pending Windows updates, and make sure the system drive has free space.

✓What to check:
  • Back up important files first.
  • Install updates from Windows Settings.
  • If the problem began immediately after an update, note that detail for support.
