USB Device Not Recognized

3 Check the cable or device.

If the device uses a detachable cable, try a known-good compatible cable. Test the device on another trusted computer if available.

✓What to check:
  • Check for cable cuts or bent connectors.
  • Test one device at a time.
  • If another PC also cannot detect it, the accessory may need service.
